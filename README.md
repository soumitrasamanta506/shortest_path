# 🧭 Visualization of Shortest Path Algorithm

A **real-time algorithm visualization tool** that demonstrates how **Dijkstra’s Algorithm** and **Breadth-First Search (BFS)** find the shortest path between nodes.  
Built with **HTML5 Canvas**, **CSS**, and **JavaScript**, this project helps users visually understand graph traversal and pathfinding concepts interactively.

---

## 🚀 Features

- 🧠 **Algorithm Visualization** — Real-time animation of Dijkstra’s and BFS algorithms  
- 🎨 **Interactive Grid** — Users can create walls, set start/end nodes, and visualize the path  
- ⚡ **Optimized Rendering** — Efficient data structures and animation cycles for smooth performance  
- 🧩 **Dynamic User Interaction** — Responsive controls and easy reset for multiple runs  
- 🌍 **Deployed Live** via GitHub Pages
